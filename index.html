> Universal Studio

Go · pdfcpu · pdf.js · Docker
  • 150+ browser-based tools across PDF, image, video, audio, text, QR, calculator and developer utilities.
  • Go API on pdfcpu: merge, split, extract, rotate, watermark, page numbers, compress, AES-256 encrypt/unlock — each request in an isolated temp dir deleted right after, so no file persists.

> HushCard

Go (stdlib-only) · Vanilla JS · OAuth
  • "Say it, don't sign it" — build a customisable card (themes, patterns, prompts, reactions), share it, receive anonymous messages.
  • Zero-dependency Go backend: salted iterated password hashing, HttpOnly/SameSite sessions, Google & Apple OAuth, per-IP rate limiting, content filtering, security headers.
  • One process serves the REST API and a no-build vanilla-JS SPA (auth, dashboard, card builder, inbox, public page).
